Capabilities

Unified rule semantics

The same DSL rules used for simulation are directly reused on real hardware. No rewriting required when transitioning from SIL to HIL.

CSV timeline ingestion

Signal timelines exported by simulation environments ingested as-is. No adapter configuration required for standard CSV formats.

Requirement coverage mapping

Each verdict maps back to the DSL rule and originating requirement. Coverage gaps visible before hardware integration.

Regression baseline

Simulation run results stored as baseline. Subsequent model changes validated against the same rules for regression detection.

Use Cases

Model validation (MIL/SIL)

Validate Simulink or FMU model output against DSL-defined behavioral requirements early in the development cycle.

Pre-hardware requirement check

Verify requirement coverage and behavioral correctness before ECU hardware or test bench is available.

Continuous integration validation

Run simulation-based DSL validation as a CI pipeline step. Automated PASS/FAIL verdict on every model commit.
