Capabilities

CAN candump + DBC decoding

Raw candump logs decoded using DBC signal definitions. Physical values available directly in DSL rules.

Unified frame format

CAN, CSV, and UART sources normalized into one adapter-agnostic frame structure. One rule set runs across all sources.

Validation optimization

Baseline run metrics drive selective re-execution. Only changed or at-risk validations are re-run in subsequent passes.

Reproducible replay

Identical log file produces identical verdict output on every replay. Deterministic behavior guaranteed regardless of execution environment.
