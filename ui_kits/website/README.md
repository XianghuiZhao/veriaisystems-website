# VeriAI Systems — Website UI Kit

## Overview
High-fidelity recreation of the VeriAI Systems marketing website prototype.

**Design width:** 1280px (responsive down to mobile)
**Theme:** Dark-first (default dark mode, light mode supported)
**Stack:** React + Tailwind via CDN, Lucide icons, Inter + JetBrains Mono fonts

## Screens
- `index.html` — Full click-thru website prototype (gate → home → platform → products)

## Components
- `Navbar.jsx` — Fixed top nav with logo, links, lang toggle, theme toggle
- `Footer.jsx` — Brand, nav links, legal, copyright
- `Hero.jsx` — Homepage hero section
- `PlatformPage.jsx` — Platform page: how it works, capabilities, paradigm cards, demo, philosophy, FAQ
- `ProductsPage.jsx` — Products page: engineering product grid

## Usage
Open `index.html` in a browser. Use the nav to move between sections.
The gate screen is bypassed for prototyping purposes.
